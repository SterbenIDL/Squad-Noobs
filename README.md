SQUAD NOOBS: אליפות קרבות רחוב 2D

מופעל באמצעות מנוע המשחק IDL Engine V1.0

ברוכים הבאים ל-SQUAD NOOBS (Brawler Clash 2D), משחק ארקייד מרהיב ועוצמתי בסגנון 2D המשלב לוחמי אנימה ייחודיים, כוחות אלמנטריים מתקדמים, מערכת פריים-דאטה (Frame Data) מדויקת, מעקב קומבואים, ואפקטים ויזואליים מהממים.

🎮 תכונות עיקריות

4 לוחמי אנימה ייחודיים:

איבן (Ivan): מאסטר הסערה והרוח-חשמל (מהירות, זריזות וברקי שמים).

עידן (Idan): אגרוף התופת האפלה (כוח אש הרסני ונובה אפלה).

פיליפ (Philip): טיטאן הקריסטל והשמש (הגנת קריסטל איתנה וקרני שמש סולאריות).

רוני (Roni): אדון המים והדם (שרידי מים זורמים ומגל דם רותח).

3 זירות קרב מרתקות: סמטת ניאו-טוקיו, מקדש הלבה והתופת, ומנחת הסערה והרעמים בגורד שחקים.

מערכת קרב מתקדמת מבית IDL Engine:

דיוק פרימים (Startup, Active, Recovery, HitStun, BlockStun).

מונה קומבואים דינמי, רעידות מסך (Screen Shake), ואפקטי פגיעה (Hit-Stop).

התחמקות דאש (Dash) עם עקבות רוח (Ghost Trails).

התקפות אולטימייט אלמנטריות עוצמתיות עם אפקטים קולנועיים על כל המסך.

מצבי משחק שונים: שחקן נגד שחקן (PvP באותה מקלדת), קרב נגד בוט מחשב חכם (AI), ומצב אימונים מלא (Training Mode) עם בובת אימון ומד אולטימייט אינסופי.

מנוע סאונד סינתטי (Arcade Audio Engine): אפקטים קוליים המופקים ב-Web Audio API יחד עם שירי פסקול אנימה אגדיים.

🕹️ מקשים ובקרת שליטה

שחקן 1 (מקלדת ראשית)

תנועה: A (שמאלה) / D (ימינה)

קפיצה: W

חסימה: החזק S

דאש (התחמקות מהירה): Q (שמאלה) / E (ימינה)

מכות קלות: Space או J (ג'אב מהיר) / C או K (בעיטה)

מכות כבדות: F או H (כבד 1) / G أو I (כבד 2)

מתקפת אולטימייט: Y, U, O, או T (דורש 100% במד האולטימייט)

השהיה (Pause): Escape או P

שחקן 2 (במצב PvP)

תנועה: חיצים ArrowLeft / ArrowRight

קפיצה: חץ למעלה ArrowUp

חסימה: החזק חץ למטה ArrowDown

דאש: [ (שמאלה) / ] (ימינה)

מכות קלות: Shift / Numpad 1 | / / Numpad 2

מכות כבדות: . / Numpad 4 | ; או L / Numpad 5

מתקפת אולטימייט: Enter / Numpad 0

🚀 התקנה והפעלה

שכפל או הורד את הפרויקט למחשב שלך.

התקן את התלויות (Dependencies):

npm install


הפעל את שרת הפיתוח המקומי:

npm run dev


היכנס לכתובת שתוצג במסוף הדפדפן (http://localhost:5173) ותתחיל לשחק!
